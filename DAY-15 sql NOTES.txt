Queries and sub-queries
-------------------
what is sub-query? 
-------
A subquery is a query inside another query
It is written inside paranthesis() and its result is used by the outer query.
It is also called as inner query, nested query, inner select.

purpose of subquery
------------
1. to break down complex problems into smaller queries
2. to use the result of one query as input to another
3. to avoid multiple steps(write in a single query instead of temp tables)

general syntax
-------------
select column-list from table
where column OPERATOR(select column from table where condition);

Types of sub-queries
---------------

1. single row-subquery
------------
single row subquery returns exactly one row and one column.
they use comparison operators like =,>,<,<=,>=,!=

characteristics
-------------
1. returns only one value.
2. can use single-value comparison operators.
3. if subquery returns no rows or multiple rows it causes an error.

syntax
--------
select columns
from table
where column operator(select column from table where condition);

2. multi-row subquery
------------
(a). multi row-subquery IN
-----------------
A multirow subquery returns more than one row. the IN operator is used to then you want to compare a value with multiple values returned by the subquery.

characteristics
------------
1. returns multiple rows.
2. use the IN operator
3. checks whether a value exists in the list returned by the subquery
4. equivalent to multiple or condition
5. most commonly used for matching values.

syntax
--------
select column from a table
where column IN(select column from table where condition);

(b). multi row-subquery (ANY/SOME)
--------------------------
multi row subqueries returns multiple rows. when using ANY or SOME. the condition is true if it matches at least one value returned by the subquery.

characteristics
-------------
1. returns multiple values.
2. ANY and SOME are interchangble
3. condition is true if any of the values satisfy the condition.
4. often used with IN,>ANY,<ANY,<=ANY,....etc

syntax
-----------
select column from a table
where column  operator ANY/SOME(select column from table where condition);

(c). multi row-subquery ALL
---------------------
the all operator means the condition must be true for all values returned by the subquery.

characteristics
-------------
1. conditions must be true for all values in the subquery result.
2. often used with >ALL,<ALL,<=ALL,>=ALL
3. >ALL means greater than the minimum value
4. <ALL means less than minimum value.

syntax
-----------
select column from a table
where column  operator ALL(select column from table where condition);


3. nested subquery
-------------
nested subqueries are subqueries within subqueries. they can be multiple levels deep and are executed from innermost to the outermost.

characteristics
---------------
1. multiple levels of nesting
2. inner queries execute first
3. can combine different types of subqueries
4. useful for complex conditions

syntax
-------------
select column-list from table
  where column=(select column from table where column=(select column from table where condition));

4. corelated subquery
-------------------
corelated subqueries are subqueries that reference columns from outer query. unlike regular subqueries that execute once. corelated subqueries execute once per each row processed by the outer query.

characteristics
------------------
1. reference column from outer query
2. executes multiple times(once per outer row)
3. cannot be execute independently
4. often used with exists/NOT exists
5. generally slower than non-corelated subqueries

syntax
---------------
select column from table1 outer_alias
  where condition(select column from table2 inner_alias where inner_alias.column=outer_alias.column);

5. exists/not exists subquery
-----------------------
Exists is used to test whether a subquery returns any rows. it returns TRUE if the subquery returns at least one row. FALSE otherwise
NOT EXISTS return TRUE if the subquery returns no rows.

characteristics
------------------
1. returns TRUE/FALSE(Boolean result)
2. more efficient than IN for large datasets
3. often used with corelated subqueries
4. stops execution as soon as first match is found
5. select clauses in EXISTS doesn't matter(often use SELECT 1)

syntax
-------------
select column from table1
where exists(select 1 from table2 where condition);

syntax
------------
select column from table1
where not exists(select 1 from table2 where condition);
