Numaric Functions:
---------------------
abs : absolute value of a number
ceil(): round up
floor() : round down
round():round to a specific number of digits.
mod(): modulo of a number
pow()/power(): exponention.
sqrt(): square root
exp() : Exponential function
Radians(): convert degrees to radians
Degrees(): convert radians to Degrees
SIGN(): Returns the sign of a number
RAND(): Generate a random number
Greatest(): Find maximum value
Least(): Find Minimum value
PI(): Return the value of P
Hexa(): Converts to HexaDecimal
OCT(): conv to OCTAL
BINARY(): conv to Binary.
LN(): natural log. (OR) log (10,100)
bit count() : bit count.
