=======UDATE=========
SYNTAX:
UPDATE TABLE-NAME SET COLUMN-NAME=VALUE WHERE SOME CONDITION;

DELETE
===========
DELETE THE ROCORDS BASED ON SOME CONDITIONS
SYNTAX :- DELETE FROM TABLE-NAME WHERE SOME CONDITION

TRUNCATE
=========
REMOVES ALL RECORDS PRESENT IN TABLE
SYNTAX : TRUMCATE TABLE TABLE-NAME;

 DIFF BTW DROP/DEL/TRUNCATE

1.DROP
===========
--> REMOVES THE TABLE OR OBJECT
-->TABLE STRUCTURE+DATA DELETED
---> TABLE STRUCTURE REMOVED
---> PERFORMANCE IS SLOW(DUE TO FULL REMOVAL)

2.DELETE
---> REMOVES SPECIFIC ROWS FROMM A TABLE
---> SPECIFIC ROWS(BASED ON CONDITION REMOVED
---> TABLE STRUCTURE INTACT
----> PERFORMANCE IS SLOWER (ROW-BY-ROW)

3.TRUNCATE
---> REMOVES ALL ROWS KEEPS STRUCTURE
---> ALL ROWS DEL
---> TABLE STRUCTURE INTACT
----> PERFORMANCE IS FAST(BULK DELETION)
