IEWS
----------
A view is a virtual table created from the result of select query

It doesn't normally stores the actual data separately instead it stores the sql query and whenever you accesses the view, MySQL retrives the data from the underlying tables.

why do we need views?
------------
SIMPLIFY COMPLEX QUERIES.
REUSE QUERY LOGIC.
DATA SECURITY.
SIMPLIFIED REPORTING.

ADVANTAGES OF VIEWS
-----------------
SECURITY
SIMPLICITY
REUSABILITY
CONSISTENCY
MAINTAINABILITY
NO EXTRA STORAGE COST


differences b/w table and view
-----------------------

         table                                             view

1.table physically stores data              1. view is virtual table based on query
2. can stores records directly              2. usually doesn't store separate records
3. create using create table                3. create using create view
4. it contain all table data                4. can show selected rows/columns
5. used for permanent data storage          5. mainly used for abstract, security, and reusable queries


alterining view
---------------------
alter view view_name as 
select new_columns from new_tables
where new_conditions;

drop a view
------------
drop view view_name

    -> select e.emp_id,e.emp_name,e.designation,d.dept_name,d.location
    -> from employees e
    -> join departments d on e.dept_id=d.dept_id;

mysql> create view vw_department_salary_summary as
    -> select d.dept_name,
    -> count(e.emp_id)as total_employees,
    -> sum(e.salary)as total_salary,
    -> avg(e.salary)as average_salary
    -> from employees e
    -> join departments d on e.dept_id=d.dept_id
    -> group by d.dept_name;
Query OK, 0 rows affected (0.02 sec)
